# 가맹 사업 희망 지역 실시간 지도 표시 웹앱 개발 계획

## 1. 개요
본 문서는 가맹 사업을 희망하는 사용자의 위치 정보(시도, 시군구)를 대한민국 지도 위에 실시간으로 시각화하는 웹 애플리케이션의 개발 계획을 담고 있습니다. 비개발 직군(기획자, 마케터 등)도 전체 구조와 개발 방향을 쉽게 이해할 수 있도록 작성되었습니다.

## 2. 시각화 전략 (UI/UX)
제공된 샘플 데이터(`briefing-applications`, `franchise-inquiries`)는 상세 주소가 아닌 **'시도'**와 **'시군구'** 레벨의 데이터만 포함하고 있습니다. 이를 지도에 표현하기 위해 다음 두 가지 방식을 혼합하여 사용하는 것을 제안합니다.

1. **마커 및 클러스터링 (추천)**
   - 각 '시군구'의 중심 좌표(위도/경도)에 마커를 찍습니다.
   - 동일한 '시군구'에 여러 건의 요청이 있을 경우, 마커에 숫자를 표시하거나 뭉쳐서 보여주는 '클러스터링' 기법을 적용하여 직관적으로 수요가 많은 지역을 파악하게 합니다.
2. **정보창 (Tooltip)**
   - 마커를 클릭하거나 마우스를 올렸을 때, 해당 지역의 상세 가맹 희망 내역(예: 신청 건수, 가맹 유형 등)을 요약해서 보여줍니다.

## 3. 기술 스택 (가장 빠르고 안정적인 조합)
- **프론트엔드 프레임워크:** React (Vite 기반) - 빠르고 가벼운 환경
- **지도 API:** 카카오맵 API (`react-kakao-maps-sdk`) - 한국 지도에 가장 최적화되어 있으며 주소-좌표 변환(지오코딩)이 강력함
- **스타일링:** Vanilla CSS (순수 CSS를 활용하여 직관적이고 커스텀이 용이하게 구성)

## 4. 데이터 처리 로직
1. **데이터 파싱:** CSV 형태의 데이터를 애플리케이션에서 읽을 수 있는 JSON 형태로 변환합니다. (향후 실시간 API가 연결되면 이 부분만 교체하면 됩니다.)
2. **좌표 변환 (Geocoding):** 카카오맵 API의 로컬 서비스를 이용해 "서울특별시 구로구"와 같은 텍스트 데이터를 지도에 찍을 수 있는 '위도/경도' 좌표로 변환합니다. 
3. **데이터 그룹화:** 변환된 좌표를 기준으로 같은 지역의 데이터를 하나로 묶어(그룹화) 지도에 표시할 준비를 합니다.

## 5. 폴더 및 파일 구조
프로젝트는 유지보수가 쉽도록 역할별로 명확하게 분리합니다.

```text
src/
├── components/          # 화면을 구성하는 UI 조각들 (재사용 가능)
│   ├── MapViewer.jsx    # 카카오맵을 렌더링하는 핵심 컴포넌트
│   ├── MarkerInfo.jsx   # 마커 클릭 시 보여질 정보창 컴포넌트
│   └── Dashboard.jsx    # 전체 레이아웃과 통계를 보여주는 화면
├── hooks/               # 데이터 처리나 상태 관리를 위한 공통 로직
│   ├── useMapData.js    # 데이터를 불러오고 좌표로 변환하는 커스텀 훅
│   └── useGeocoding.js  # 주소 텍스트를 위경도로 변환하는 로직
├── utils/               # 날짜 포맷 변환, CSV 파싱 등 단순 보조 함수
│   ├── csvParser.js     # CSV 파일을 JSON 객체로 변환
│   └── dataGrouper.js   # 지역별로 데이터를 묶어주는 함수
├── api/                 # 외부 서버나 API와의 통신 담당
│   └── mapApi.js        # 실시간 데이터 호출 (현재는 모의 데이터 연결)
├── styles/              # 화면 디자인을 위한 CSS 파일 모음
│   ├── index.css        # 전체 디자인 토큰 및 기본 스타일
│   └── map.css          # 지도 관련 커스텀 스타일
├── App.jsx              # 앱의 진입점이자 메인 컴포넌트
└── main.jsx             # React를 브라우저에 연결해주는 최상위 파일
```

## 6. 단계별 개발 진행 순서
- **1단계 (기본 세팅):** Vite를 이용한 React 프로젝트 생성 및 카카오맵 API 연동 테스트
- **2단계 (데이터 처리):** 샘플 CSV 데이터를 읽어오고, '시도+시군구' 정보를 위도/경도 좌표로 변환하는 로직 구현
- **3단계 (지도 시각화):** 지도 위에 변환된 좌표로 마커를 표시하고, 마커 클릭 시 간략한 정보를 보여주는 UI 개발
- **4단계 (고도화 및 실시간 대비):** 동일 지역 마커 클러스터링(묶음 표시) 적용 및 향후 실시간 API 연결을 위한 구조 다듬기
